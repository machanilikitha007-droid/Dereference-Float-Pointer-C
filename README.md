# Dereference a Float Pointer in C

**Author:** M.Likitha

## Description

This program demonstrates how the dereference operator `*` is used with a float pointer to access and modify a floating-point value.

## Concepts Used

- Float variables
- Pointers
- Dereference operator `*`
- Pointer-based modification
